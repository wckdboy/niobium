SwiftUI on iOS/iPadOS, Kotlin and Compose on Android. One product spec, native surfaces, no third-party SDKs and no account in the middle.

The shape

  • gatewayYour Hermes instance. WebSocket JSON-RPC 2.0 over /api/ws; session token held in Keychain/Keystore.
  • pixelsHermes profiles. Each has a personality, permissions, toolsets, skills, connectors, a character and a companion.
  • localiOS full build embeds iSH-ARM64 + Alpine + Node + DSH. Android and iOS can open a remote DSH web UI.
  • builderbot-build.md is the agent skill; llm.oneshot produces a validated PixelSpec.
