Run the full DeepSeek Harness on an iPhone/iPad with the iOS full build, or open DSH from a computer or VPS on either platform.

On device · iOS

iSH-ARM64, Alpine 3.21, Node 22 and dsh-serve. Boots on demand, loopback only, persists sessions. 82 MB full build, GPLv3.

Remote · both

Point Niobium at the DSH web UI on your computer, GPU box or VPS. Android uses this path; the embedded AArch64 guest is iOS-only.
