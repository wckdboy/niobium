what changed

Set up DeepSeek, OpenAI, Anthropic or an OpenAI-compatible endpoint directly in the desktop app. Compatible servers have explicit model, context and output limits; unauthenticated endpoints can omit a key. Android’s key-saving screen now activates OpenAI and Anthropic model routes.

Choose a default for new chats. Existing conversations retain their model, and open model pickers refresh after setup. Provider edits preserve other settings, reject stale revisions and leave advanced custom models to DSH’s advanced controls. A failed catalog lookup does not block the other providers.

Keys remain write-only to the native client and stay in DSH’s owner-only credential file. No-auth servers use an isolated nonsecret placeholder. Configured status confirms local setup; it does not validate your provider account. CodeRabbit reviews new changes; Greptile automatic reviews are disabled.

verified

33 shared-core tests, 22 desktop tests, seven additional Android JVM tests, 85 Node checks and 15 Python checks. Real pinned DSH streams DeepSeek, OpenAI Responses, Anthropic Messages and compatible chat against local fixtures, then restores the original conversation after restart. No real account or billable model request is used.

The provider activation test and existing DSH streaming/rooms regression pass separately on the ARM64 Android 16 emulator. The signed APK upgrades and cold-launches; lint, runtime hashes and 16 KB ELF/ZIP packaging checks pass. Native Linux and macOS CI exercises app images, actual packaged launchers and extracted or mounted installers.
