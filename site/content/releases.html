what changed

Clear stepped keyboard focus, selected page/engine/appearance roles and labeled toggles make the pixel controls easier to use. Saved-account actions identify the account. The native View → Text size menu offers 100%, 125% and 150%, and remembers your choice.

Engine setup and welcome content reflow to fit. Workshop permissions stay reachable at larger text sizes; Escape closes an idle workshop and restores focus to its opener. Chat preserves your position while you read older messages. Latest messages resumes following, including replies taller than the viewport after text wraps. Streaming keeps your draft and input focus.

the storage boundary

Vault storage protects values at rest at the OS-user level. Same-user processes and local agent tools can access saved values. The unsigned helper does not validate a signed parent, and Linux Secret Service shares the user session. Session-only use is the default. DSH provider keys keep their owner-only file; its vault bridge remains separate work.

verified

55 desktop, 33 shared-core, seven additional Android JVM, 85 Node and 15 Python checks. Twelve native UI cases cover keyboard controls, 2,000-message history, enlarged text, narrow/HiDPI setup, tall replies, resize following and workshop focus.

The real bundled DSH runs three isolated start/connect/stop cycles with nine DM and three room turns, fake HTTP/SSE, cold history/appearance restoration, exact room event counts and zero remaining observed owned processes. Receipts record live owned-process CPU/RSS. These short baselines do not establish multi-hour performance or measure the UI JVM.

Both native vault suites and Linux/macOS installer checks pass. No real provider account or billable model request is used.
