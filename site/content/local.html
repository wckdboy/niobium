DeepSeek Harness can run beside your Hermes team. The iOS full build embeds an Alpine Linux guest through iSH. Both platforms can connect to a DSH web UI on a computer or VPS.

on your device

The iOS full build bundles iSH-ARM64, Alpine, Node and DeepSeek Harness. Opening DSH boots the guest on demand. The harness has its own terminal, workspace, sessions, logs and restart controls. Guest data persists between app launches.

Enter provider API keys in the harness. The Linux runtime is local; model inference still uses the selected provider unless you configure a separate local model endpoint. Phone GPU or memory figures are not presented as model-runtime telemetry.

on your computer or vps

Start DSH’s web server and enter its HTTP or HTTPS address in Niobium. The app opens the real harness interface. Use an authenticated endpoint reachable from your phone.

Android currently uses this remote path. An embedded Android Linux runtime is not shipped. iSH is an iOS integration and cannot simply be switched on in the Android build.

build notes

The iOS full build is GPLv3 and requires the pinned DSH/iSH submodule and generated root filesystem. It is distributed through source builds and suitable signing, not advertised as an App Store release. The smaller Hermes-only iOS target leaves the Linux guest out.
