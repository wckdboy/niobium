No Hermes server connected? Run local Pixels with DeepSeek Harness. Niobium embeds Alpine Linux on iOS and ARM64 Android, and can also open DSH on your computer or VPS.

on your device

Choose “Run Pixels locally” on the welcome screen, or open the Local tab. iOS uses iSH-ARM64; Android uses an APK-packaged PRoot engine. Both include a pinned Alpine, Node and DSH image. Start the engine, open the workspace, and enter your provider API keys in DSH settings.

The Linux runtime is local. Model inference uses your selected provider unless you configure a reachable model endpoint. Android needs about 450 MB for the installed image. Stop closes the engine and its tasks; your workspace remains on the device.

a little linux lab

Android has pixel icons, stepped controls, installation progress and a foreground notification with Stop. Its DSH interface uses a private guest socket and an authenticated local connection. Provider settings stay in private DSH storage. Pixels share the guest workspace.

The bundled bot-build skill designs a persona, look, access and companion for review. DSH has its own sessions and agent presets. The native Hermes workshop is not yet a DSH preset editor.

on your computer or vps

Start DSH’s web server and enter its HTTP or HTTPS address in Niobium. Use an authenticated endpoint reachable from your phone. Remote DSH remains available on both platforms.

beta coverage

The Android runtime passes app-sandbox tests for shell, Node, DSH, authenticated HTTP/WebSocket access, session creation, skill discovery, Start/Stop, WebView layout and workspace preservation. Physical-device battery behaviour, 16 KB page-size operation, provider-backed turns and native host bridges still need acceptance testing.
