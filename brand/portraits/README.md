# Character portraits

CC0 portraits by **Hyptosis** ("Cyberpunk Portraits", OpenGameArt, 2022).
https://opengameart.org/content/cyberpunk-portraits

The pack is CC0 / public domain. It is used here as the base portrait
catalog for the character engine. The 96×96 cells are extracted from
three 4×2 sheets by `tools/make_portraits.py`.

Adults only. Mature styling; no explicit content. Companions and frames are
original Niobium pixel art.
